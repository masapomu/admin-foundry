# Internationalization contract

i18n readinessは必須。翻訳ランタイムの指定はしない。Symfony Translation / gettext / ASP.NET Localizer / .resx / Perl Locale / 独自実装など、hostが選択する。

## Encoding and language

- UTF-8でHTML/CSS/JSを保存し、HTTPにもcharsetを指定する。
- 文書の主言語に合わせて `<html lang="en">` または `<html lang="ja">` 等を出力する。
- 比較ページは英語を主言語とし、日本語/ドイツ語の領域に `lang="ja"` / `lang="de"` を付ける。
- ラベル、alt、title、aria-label、validation、flash、data属性も翻訳対象。

## Semantic message keys

| Key | English | 日本語 |
|---|---|---|
| common.save | Save changes | 変更を保存 |
| common.cancel | Cancel | キャンセル |
| common.delete | Delete | 削除 |
| common.ok | OK | 確認 |
| common.yes | Yes | はい |
| common.no | No | いいえ |
| nav.dashboard | Overview | 概要 |
| nav.users | Users | ユーザー |
| error.load_failed | Unable to load. | 読み込めませんでした。 |
| table.no_results | No matching records. | 一致するデータがありません。 |
| selection.count | {count} selected | {count} 件選択中 |

Keyは意味を表し、翻訳文やページ位置をkeyにしない。hostのsyntaxは自由。

## Strings passed into JavaScript

```html
<button type="submit" data-ui-confirm data-confirm-kind="danger"
  data-confirm-title="ユーザーを削除しますか？"
  data-confirm-message="この操作は取り消せません。"
  data-confirm-cancel="キャンセル" data-confirm-button="削除">削除</button>
```

共通JSは文字列をtextContentへ渡すだけ。英語のYes/No/Save/Delete等をハードコードしない。HTML属性にはhostの適切なattribute escapingを適用する。文章片の連結やinnerHTMLでの挿入を行わない。

コピー成功/失敗、password表示切替、toast、アカウントメニューも同じ契約。`data-copy-success` / `data-copy-error` / `data-label-show` / `data-label-hide` / `data-ui-toast` / `data-confirm-*` に完成済み文言を渡す。`i18n.html` には日本語の通知、アカウントメニュー、ログアウト説明を表示例として含める。

選択件数の初版は独立した数値と、文法変化しないラベルの例。複数形が変わる言語ではhostがICU-compatible message format等で完全なメッセージ群を出力し、数値によって適切な文を選べるadapterを提供する。共有JSにplural ruleを足さない。

## Date / time / number

host側でlocaleとtimezoneを指定して整形する。HTML timeのdatetimeにはISO 8601を使う。表示とmachine-readable valueを分ける。

- en-US: Sep 25, 2026, 9:42 AM UTC / 1,248.50
- ja-JP: 2026年9月25日 18:42 JST / 1,248.50
- de-DE: 25.09.2026, 09:42 UTC / 1.248,50

上記の日時は同じ瞬間。JavaScriptで場当たり的に日付文字列を連結しない。native date/timeはブラウザーの表示ロケールに従い、valueは規定の機械形式。datetime-localはtimezoneを含まないので、ラベルとサーバーの解釈を揃える。

## Text expansion and Japanese

操作ボタンは内容幅、toolbar/actionsはwrap、gridはminmax(0,1fr)。固定幅の英語ラベル前提を避ける。日本語の長い文は自然に折り返し、長いID/emailはtableの横scrollで読める。行高は最低値であり固定しない。省略で重要な意味を消さない。

日本語はsystem font fallbackを使い、文字の欠落、行間、ボタンの縦位置、エラーメッセージの折返しを目視確認する。全角/半角、氏名順、数値単位、複数形はhostの翻訳仕様に従う。

## Language selector

国旗を使わずEnglish / 日本語等の自称表記を使う。referenceは比較領域へのリンク。本番のlocale保存はcookie/session/user setting/Accept-Language等でhostが決定する。全ページの言語を切り替えるclient-side translation runtimeは実装しない。

初版でRTLや全言語を検証したとは扱わない。RTL導入時はBootstrap RTL、logical properties、配置を追加検証する。
