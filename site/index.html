Get started

How to install in Codex

Add the AdminFoundry marketplace, then install the plugin. The admin-foundry:server-rendered-admin-ui skill and reference UI come bundled with it.

Start a new Codex task and ask it to use the skill for a server-rendered admin UI. No separate skill installation is needed.

Direct GitHub installation; this is not a listing in the official public Plugins Directory.

codex plugin marketplace add masapomu/admin-foundry --ref main
codex plugin add admin-foundry@admin-foundry-local
Server-rendered first Bootstrap 5.3 No CDN required i18n-ready Codex skill included
